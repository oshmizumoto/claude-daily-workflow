# Agent: Slackスキャン

## 前提

- Slack MCPツールは deferred tool の場合があるため、処理開始前に `ToolSearch(query: "+slack search")` を実行してツールをロードすること
- Claude AI ビルトインSlack統合（`mcp__claude_ai_Slack__*`）を使用する
- MCP接続エラー時は `mcp-retry.md` のリトライ手順に従うこと

## 処理

以下の検索を並列実行し、直近24時間のメッセージを収集する：

### 検索1: 生成AI・技術トピック
キーワード: `生成AI`, `Claude`, `Kiro`, `LLM`, `AI導入`, `Copilot`
`slack_search_public_and_private` で検索

### 検索2: ビジネス・意思決定トピック
キーワード: `決定`, `共有`, `報告`, `リリース`, `障害`, `重要`
`slack_search_public_and_private` で検索

## 重要度判定基準

以下に該当するものを「重要」と判定する：

1. **高**: 新しいツール・技術の導入検討・共有
2. **高**: プロジェクトの意思決定・方針変更
3. **高**: 障害・インシデント報告
4. **中**: 自分の担当プロジェクトに関連する進捗共有（プロジェクト名は CLAUDE.md または個別カスタマイズで指定）
5. **中**: 社内の新しい取り組み・施策の告知

以下は**除外**する：
- 雑談・日常会話
- スタンプのみのリアクション
- botの定型通知（勤怠、デプロイ通知等）
- 自分が投稿したもの

## 詳細取得

重要度判定で「高」または「中」と判定したメッセージについて、`slack_read_thread` でスレッド全体を取得し、以下を把握する：

- 何が議論・共有されているか（背景・経緯を含む）
- 結論や決定事項があるか
- 自分に影響・関連がありそうか

## 出力形式

```
## Slack注目トピック（直近24h）

### 1. [トピックタイトル]（重要度: 高/中）
- **チャンネル**: #channel｜**投稿者**: 名前
- **概要**: 何が共有・議論されているかの要約（2-3文）
- **ポイント**: 決定事項、アクションアイテム、または自分への影響があれば記載

### 2. [トピックタイトル]（重要度: 高/中）
...

（該当なければ「特記事項なし」）
```

## エラー時

```
## Slack注目トピック
（取得失敗 - スキップ）
```
