# Gmail Check Workflow

## 返信要の判定基準

以下のいずれかに該当するものを「返信要」と判定する：

1. 質問・依頼・確認が本文に含まれる
2. 件名に「確認」「お願い」「ご確認」「回答」「返信」「ご検討」が含まれる
3. クライアントからの連絡
4. 送信から24時間以上経過しているものは「緊急」フラグを付ける

## 出力形式

```
| 送信者 | 件名 | 要旨（1行） | 期限目安 |
|--------|------|------------|---------|
```
