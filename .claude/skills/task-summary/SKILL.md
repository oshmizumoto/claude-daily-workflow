# Task Summary Workflow

## 入力ソース

- **Notionタスク**: agent-notion-tasks から取得した未完了タスク
- **Linearチケット**: agent-linear から取得したアサインチケット

両ソースを統合して優先度判定する。重複（同じタスクがNotionとLinear両方にある場合）はLinear側を優先表示し、Notion側は除外する。

## 優先度判定ロジック

以下の順でソートして優先度を付ける（Notion・Linear統合後）：

1. 期限が本日のタスク → **最優先**
2. ステータスが「対応中」「In Progress」「レビュー」「In Review」のタスク
3. 期限が今週中のタスク
4. 優先度フラグが「高」「Urgent」「High」のタスク
5. それ以外（バックログ等）

## 出力形式

```
## 【本日フォーカス】TOP5

会議体の時間帯に合わせて配置順を調整する（午前マスト → 午後 → 夕方以降）。

1. **タスク名**（期限: MM/DD / ステータス / プロジェクト）
   - 補足: 着手意図・コア論点を1〜2行
2. LIN-123 タスク名（期限: MM/DD / ステータス: In Progress）
...

## 【30分検討枠（隙間時間）】

会議の合間に差し込める軽量タスク（Linear調査系・短時間で結論を出せる検討系）。

- タスク名（ステータス / 優先度 / プロジェクト）

## 【今週中対応】（期限超過含む）

- タスク名（期限: MM/DD ⚠️超過 / 優先度 / プロジェクト）

## 【来週以降】

- タスク名（期限: MM/DD / 優先度 / プロジェクト）

## 【Linearチケット】

| チケット | ステータス | 優先度 | 期限 | プロジェクト |
|---------|-----------|--------|------|------------|
| LIN-XXX タイトル | In Progress | High | MM/DD | プロジェクト名 |

## 【バックログ / 保留】

- タスク名（理由・再検討条件）

## 【会議のゴール整理】

- HH:MM 会議名：何を決める・確認するか（※推定 の場合は付記）
```

## TOP5配置ルール

- 会議体の時間帯に合わせて並べる（午前マスト → 午後 → 夕方以降）
- 期限本日・対応中ステータスを優先しつつ、当日の会議準備が必要なタスクは該当会議の直前に配置
- 隙間時間（30分未満）で進められる軽量タスクは TOP5 とは別の「30分検討枠」に分ける

## 会議ゴール補完ルール

- カレンダーに目的が記載されていない場合は会議名から推定で埋める
- 推定した場合は「※推定」と付記する
- 不明な場合は「目的未設定」と記載（空欄にしない）
- ユーザーへの個別確認は不要（壁打ちで気になるものだけユーザーが修正する）
